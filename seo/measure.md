# Measurement plan

Local QA baseline: 2026-10-16. Not deployed in this task. Search/analytics values are unknown, not zero.

Parent owns release, GA4/GSC/Bing/AdSense account configuration and consent-platform verification. PUBLIC_GA4_ID and verification identifiers are empty by default. Do not claim live measurement until installed and verified.

## Day 0 after actual deployment
Record deployed commit, public asset hashes, sitemap URLs/statuses, canonical HTML, real 404, robots headers, noindex exceptions, data asOf, mobile interaction checks. Submit sitemap and configured IndexNow key only after public ownership/release verification. Record GSC/Bing indexed pages, last 28-day impressions/clicks/CTR/position by font/tool/guide group and GA4 tool_used events. Check regional consent with a certified CMP; Consent Mode defaults alone are not a consent interface.

## Day +14
If deployed 2026-10-16, target 2026-10-30; otherwise shift to actual release +14 days. No reminder or routine was enabled here. Compare equal windows excluding the latest 2–3 days. Inspect indexed/excluded URLs and crawl failures. Test 5 questions: OFL commercial use, Google Fonts logo use, web versus desktop licence, variable font axes, fluid type scale. Record exact query, engine, date, answer and cited URL; absence of citation is not proof of technical failure. Track available bot access logs without claiming identification from user-agent alone.

## Decisions
Zero exposure: inspect indexing, robots, canonical and discovery before rewriting. Impressions up/clicks down: inspect intent and snippets. Position 5–15: improve source-specific answers/internal links. Source/licence changes: refresh actual facts and date, rebuild/gate. Never change dates merely for freshness. Quarterly: entity consistency and model recall; no ranking, approval or revenue guarantees.
